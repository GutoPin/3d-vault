Elige tu carpeta

Se hace una sola vez. Dentro aparecerá una carpeta por cada proyecto que marques.

  1. Crea una carpeta para 3D-Vault, por ejemplo D:\3D-Vault o Documentos\3D-Vault. Windows no deja usar Documentos ni el Escritorio directamente: tiene que ser una carpeta dentro.
  2. Pulsa el botón, elige esa carpeta y acepta Ver archivos y Guardar cambios.
  3. Marca los proyectos que quieres tener en tu PC.

Permite el acceso a tu carpeta

El navegador vuelve a preguntar cada vez que abres la página. Si te ofrece Permitir siempre, elígelo.

Instalar como aplicación

Tendrá su propia ventana e ícono en la barra de tareas. Después, en Edge abre edge://apps, haz clic derecho sobre 3D-Vault y marca Iniciar automáticamente al iniciar sesión: así se sincroniza desde que enciendes la PC.

Si no ves el botón: menú ⋯ del navegador → Aplicaciones → Instalar este sitio como aplicación.

Conectar Blender

Un panel dentro de Blender (tecla N → 3D-Vault) para bloquear, guardar y subir, y actualizar, sin salir de Blender. Te avisa al abrir un archivo si hay una versión más nueva o lo tiene otro.

  1. Descarga el complemento.
  2. En Blender: Editar → Preferencias → Complementos, menú ⌄ arriba a la derecha → Instalar desde el disco, y elige el archivo descargado.
  3. Pulsa Generar código, cópialo y pégalo en las preferencias del complemento. Blender no guarda tu contraseña.
