Cómo leer la tabla

Tamaño actual suma la última versión de cada archivo, sin comprimir. En disco es lo que ocupan, comprimidos, los trozos de todas las versiones del proyecto, contando cada trozo una vez.

Un trozo que comparten varios proyectos cuenta en cada uno, así que la columna puede sumar más que el total guardado en disco.

Liberar espacio

Se hace en el VPS, con el servidor detenido. Haz antes una copia de seguridad.

Sin --apply, cada comando solo muestra lo que haría. purge conserva siempre la versión actual de cada archivo, las 10 últimas y las de los últimos 180 días, y quita del todo los archivos borrados hace más de 180 días. gc borra después los trozos que ya no usa ninguna versión.

cd ~/3d-vault/deploy
sudo docker compose stop server
sudo docker compose run --rm server purge --keep-last 10 --older-than 180d
sudo docker compose run --rm server purge --keep-last 10 --older-than 180d --apply
sudo docker compose run --rm server gc --apply
sudo docker compose up -d server
{{end}}
